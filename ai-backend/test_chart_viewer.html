🌟 Birth Chart SVG Viewer

Test your astrological birth chart visualizations

Method 1: View Chart by ID

Enter the chart ID you received from the API to view the SVG visualization.

Steps:
  1. Go to Swagger UI: http://localhost:8000/docs
  2. Use POST /api/v1/birth-chart/calculate to create a chart
  3. Copy the chart_id from the response
  4. Paste it below and click "Load Chart"
📌 Direct URL: You can also open directly in browser:
http://localhost:8000/api/v1/birth-chart/{chart_id}/svg

⚠️ Important: Don't forget the /api/v1/ prefix!
